Lupin
Docs crates.io GitHub

Hide data inside PDF, PNG, JPEG, MKV and WebM files

Drop a file to hide a message in it, or to read a message hidden with Lupin. Everything runs in your browser; your files are never uploaded.

What to hide

Lupin hides data but does not encrypt it. Encrypt anything sensitive first.


            
          

        


        

          
Installation

          
Command line

          
cargo install lupin

lupin embed document.pdf secret.txt output.pdf
lupin extract output.pdf recovered.txt

          
Rust library

          
cargo add lupin --no-default-features

          
See the API documentation on docs.rs.
